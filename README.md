# Portofolio Pribadi - Kornelius

Selamat datang di repositori kode untuk situs web portofolio pribadi saya. Situs ini dibangun untuk menampilkan profil, keahlian, dan berbagai proyek pengembangan sistem yang telah saya kerjakan sebagai pengembang backend dan lulusan Sistem Informasi di Universitas Riau.

## Teknologi Utama

Situs web ini dibangun menggunakan ekosistem modern untuk menghasilkan antarmuka yang cepat dan interaktif:

* **Framework:** React
* **Desain Antarmuka:** Aceternity UI
* **Styling:** Tailwind CSS
* **Hosting dan Deployment:** Vercel

## Fitur Proyek

* Desain responsif yang berjalan lancar di berbagai perangkat.
* Animasi dan komponen antarmuka modern menggunakan Aceternity UI.
* Bagian khusus untuk memamerkan proyek pengembangan web dan penelitian data.

## Menjalankan Proyek Secara Lokal

Jika Anda ingin menjalankan atau memodifikasi kode ini di mesin lokal, silakan ikuti langkah-langkah instalasi berikut:

1. Kloning repositori ini ke dalam komputer lokal.
2. Buka terminal atau command prompt lalu arahkan ke direktori proyek.
3. Ketik perintah `npm install` untuk memasang semua dependensi yang diperlukan.
4. Setelah instalasi selesai, jalankan `npm run dev` untuk memulai peladen pengembangan.
5. Buka peramban web dan akses alamat localhost yang tertera pada terminal.
